# News Headline Classification  
### Method A (N-gram LM) vs Method B (SentenceTransformer)

This repository contains the code used to run two news classification models:
- **Method A:** Class-conditional N-gram Language Model  
- **Method B:** SentenceTransformer embeddings + Logistic Regression  

All experiments in the report can be reproduced by running the scripts in this repo.

---

## 1. Requirements

### **Python version**
Python 3.9+

### **Install dependencies**
```bash
pip install numpy pandas scikit-learn sentence-transformers tqdm
```

Or if using a virtual environment (recommended):

## 2. Data Files

The following data files are required:

- **`training_data.csv`**: Real training data (120,000 samples)
  - Format: CSV with columns `text` and `label`
  - Labels: 0=World, 1=Sports, 2=Business, 3=Sci/Tech

- **`test_data.csv`**: Real test data
  - Format: CSV with columns `text` and `label`
  - Used for evaluating models on real data

**Note**: Make sure these files are in the `llm_classify/` directory before running experiments.

## 4. How to Run Experiments

### **Option 1: Unified Experiment (Recommended for Quick Verification)**

This experiment verifies both expectations in one run:
1. **Expectation 1**: On real data, Embedding > N-gram
2. **Expectation 2**: On synthetic data (generated by n-gram), N-gram > Embedding

**Run command:**
```bash
cd llm_classify
python unified_experiment.py
```

**What it does:**
- Loads 10,000 samples from real training data (for faster execution)
- Trains n-gram model on real data
- Tests n-gram and embedding models on real test data (Expectation 1)
- Generates 100 synthetic samples per class from n-gram model
- Tests both models on synthetic data (Expectation 2)
- Outputs results to `unified_experiment_results.txt`

**Expected runtime**: ~2-5 minutes (depending on hardware)

---

### **Option 2: Full Synthetic Data Experiment**

This is the main experiment that tests both models on synthetic data with more detailed analysis.

**Run command (fast mode - recommended for testing):**
```bash
cd llm_classify
python synthetic_data_experiment.py --fast-mode
```

**Run command (full dataset):**
```bash
cd llm_classify
python synthetic_data_experiment.py
```

**Run command (custom parameters):**
```bash
cd llm_classify
python synthetic_data_experiment.py --max-train-samples 50000 --n-per-class 500
```

**Command-line arguments:**
- `--fast-mode`: Use reduced dataset (20,000 training samples, 200 synthetic samples per class) for faster execution
- `--max-train-samples N`: Maximum number of training samples to use (default: None = use all data)
- `--n-per-class N`: Number of synthetic samples to generate per class (default: 500)

**What it does:**
1. Loads real training and test data
2. Trains n-gram model on real training data
3. Evaluates n-gram model on real test data (for reference)
4. Generates synthetic data by sampling from trained n-gram model
5. Tests n-gram model on synthetic data (with uniform prior)
6. Trains and tests embedding model on synthetic data
7. Compares performance of both models
8. Outputs detailed results to `synthetic_data_experiment_results.txt`

**Expected runtime:**
- Fast mode: ~5-10 minutes
- Full dataset: ~30-60 minutes (depending on hardware)

## 7. Troubleshooting

### **Common Issues**

1. **FileNotFoundError: training_data.csv not found**
   - Make sure you're running the script from the `llm_classify/` directory
   - Verify that `training_data.csv` and `test_data.csv` exist in the current directory

2. **Memory errors with full dataset**
   - Use `--fast-mode` flag for reduced dataset
   - Or use `--max-train-samples` to limit training data size

3. **Slow execution**
   - Use `--fast-mode` for faster testing
   - The first run may be slower due to downloading SentenceTransformer model

4. **Import errors**
   - Make sure all dependencies are installed: `pip install numpy pandas scikit-learn sentence-transformers tqdm`
   - If using virtual environment, make sure it's activated
